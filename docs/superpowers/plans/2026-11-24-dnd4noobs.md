# dnd4noobs on the planet: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dnd4noobs to the portfolio as a project card, a tavern landmark with Pip in the Personal Projects district, a guide line and a gallery captured from a local run of the app.

**Architecture:** Follow the existing project pattern: content in `content/projects.ts` and `content/guide.ts`, a place in `content/world.ts`, a landmark component built from the kit (`components/world/models/kit.tsx`) and registered in `registry.ts`, and a one-line per-landmark test. Screenshots come from a Playwright script modelled on `scripts/capture-realm.ts`.

**Tech Stack:** Next.js 15, React 19, three.js / react-three-fiber, Vitest, Playwright, tsx.

**Spec:** `docs/superpowers/specs/2026-11-24-dnd4noobs-design.md`

## Global Constraints

- Work on branch `feat/dnd4noobs`. Never push or deploy.
- Commit messages carry no `Co-Authored-By` or AI-attribution trailer (a hook rejects them).
- No real names of Kylee's kids or family profiles in code, file names, alt text or screenshots. Captures use a fresh local test account and made-up hero names.
- Kylee's copy is marked `DRAFT` in a comment above it, for her review.
- The landmark follows `components/world/models/README.md` (the kit's manual): stylised anime look, not a toy; footprint inside its allowed radius; no taller than 2.6; within `TRIANGLE_BUDGET` 24,000 and `DRAW_BUDGET` 45.
- Not a d20: the night easter egg already rolls one.
- Pip's look comes from `E:\codeProjects\dnd-4-noobs\art\pip-portrait.png`: green skin, long pointed ears with gold hoops, a wide purple hat with a gold buckle and a blue-to-purple feather, a purple cloak, and a lute.
- Project values: slug `dnd4noobs`, name `dnd4noobs`, status `beta`, `liveUrl` `https://dnd4noobs.com`, `isPersonal: true`.
